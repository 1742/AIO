<h2>概述</h2>
这个mod提供了一条<b>格式塔帝国</b>的全新的化身天灾路线——<i><b>万物归一</b></i>。通过提升天灾等级、执行定向应用无限并最终完成专属巨构<i><b>犹格索托斯</b></i>实现飞升，主宰现实法则。
<br>
尽管在这条飞升路径上你还是会看到许多原版飞升的影子<del>（什么拼好灾）</del>，但经过作者（和AI）的反复折腾，现在它引入了一套全新的<b>定向应用无限</b>系统（Directional Apply Infinity Thesis, DAIT）。不再是枯燥的加成，而是直接修改宇宙的底层代码！<del>（不就是换种方式加buff吗……）</del>

<h2>内容</h2>
<ul>
<li>新增飞升<b>万物归一</b>与化身天灾路径</li>
<li>新增<b>定向应用无限</b>系列增益</li>
<li>新增一个起源万物归一</li>
<li>新增巨构犹格索托斯</li>
</ul>

<h2>核心玩法：法则编辑</h2>
和原版的3条灾飞路径一样，你需要先采纳三个飞升才能选择<b>万物归一</b>飞升。通过积累<b>超然逻辑</b>，你不再是简单的点科技，而是直接将<b>超然逻辑</b>转换成帝国修正。
现在的天灾Buff分为三类，你可以随时切换，根据你的<b>超然逻辑</b>产出线性（在数值较低时）增长。

<h2>流程攻略</h2>
<h3>天灾1级</h3>
采纳后解锁：
<ul>
<li><b>指数级学习理论：</b>解锁首都套娃脑区划与无限递归节点岗位；虚拟帝国可组装专用递归载体作为物质节点。</li>
<li><b>视界引擎：</b>产出能量和暗物质，为后续做准备。<del>（依然是以太相引擎的亲戚）</del></li>
</ul>
<h3>天灾2级</h3>
完成<i><b>视界引擎</b></i>后解锁：
<ul>
<li>升级为<i><b>万门之门</b></i>。完成时立即生成<i><b>无名之雾</b></i>，并触发一次随机应用无限。</li>
<li>解锁第一组<b>DAIT</b>操作：<b>丰饶</b>与<b>风暴</b>。</li>
</ul>
<h3>天灾3-5级</h3>
一路升级你的巨构：<i><b>银时之匙</b></i> -> <i><b>永恒王座</b></i> -> <i><b>犹格索托斯</b></i>。
<br>
每次巨构升级都会触发一次随机应用无限。天灾3、4、5级分别要求累计执行1、3、6次<b>DAIT</b>，并依次解锁<b>生成/收割</b>、<b>播种/打击</b>与<b>思潮/擦除</b>。
<br>
完成<i><b>犹格索托斯</b></i>后即完成飞升，获得游戏胜利。如果继续游戏，你可以通过犹格索托斯任意编辑现实：
<ul>
<li>改变天体类型</li>
<li>改变其他帝国政府</li>
<li>抹除天体</li>
<li>抹除银河</li>
<li>...</li>
</ul>
同样的，由于不能在无法到达的星系建造巨构，所以有很多功能都有bug...

<h2>兼容性</h2>

该mod存在移除天体、舰船等行为，可能会导致其他mod的特殊天体、星系、舰船被错误的移除导致事件链卡住。
<b>严重警告：</b>请不要使用mod的地图类型！这可能导致<i><b>无名之雾</b></i>无法生成并阻断巨构升级！
<br>

最后，享受游戏吧！
