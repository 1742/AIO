# 万物归一 (All-in-One)

<h2>概述</h2>
这个mod提供了一条全新的化身天灾路线——<i><b>万物归一</b></i>。通过提升天灾等级、执行定向应用无限并最终完成专属巨构<i><b>犹格索托斯</b></i>实现飞升，主宰现实法则。
<br>
尽管在这个野望和*宇宙创生*有点相似，但经过作者的反复折腾，现在它引入了一套全新的<b>定向应用无限</b>系统（Directional Apply Infinity Thesis, DAIT）允许你爆改宇宙。

<h2>内容</h2>
<ul>
<li>新增飞升<b>万物归一</b>与化身天灾路径</li>
<li>新增<b>定向应用无限</b>系列增益</li>
<li>新增一个起源万物归一</li>
<li>新增天灾巨构</li>
</ul>

<h2>核心玩法</h2>
和原版的3条灾飞路径一样，你需要先采纳三个飞升才能选择<b>万物归一</b>飞升。通过消耗<b>超然逻辑</b>编辑宇宙，推进天灾进度。作为文灾的变种，老登建筑和船都有，不过以现在的强度和性价比应该没人用了吧......(都什么版本了还玩循环科技爆船那套)

<h2>流程攻略</h2>
天灾升级需要同时满足超然逻辑与前置巨构条件，具体要求看天灾面板。路线是：<b>视界引擎 → 万门之门 → 银时之匙 → 永恒王座 → 犹格索托斯 → 亚弗戈蒙终局 → 选择飞升</b>。特殊起源会直接完成飞升，跳过这套流程。

<h3>天灾1级：先把脑子烧起来</h3>
采纳后，从专属科技和基础经济起步：
<ul>
<li><b>指数级学习理论：</b>解锁套娃脑区划与递归节点岗位，不再限定首都；虚拟帝国可以使用专用的实体递归载体。<del>这不突触凝练机吗</del></li>
<li><b>升维假设：</b>提供建造<i><b>视界引擎</b></i>所需的科技选项。引擎负责产能量，供你烧突触。<del>还有以太相引擎的事</del></li>
<li><b>暗物质技术：</b>开放暗物质相关科技、生产特化与法令，为后续巨构准备材料。</li>
</ul>
研究科技、完成舰船特殊项目和探索星界裂隙也能获得超然逻辑，别只盯着套娃脑。

<h3>天灾2级：开门</h3>
完成<i><b>视界引擎</b></i>并满足逻辑要求后，解锁升级<i><b>万门之门</b></i>。
<ul>
<li>万门之门建成后生成<i><b>无名之雾</b></i>，后续巨构在这里继续升级。它不承载殖民地。</li>
<li>解锁第一组<b>DAIT</b>操作：<b>丰饶</b>与<b>风暴</b>。丰饶立即生效，可以用来给星系添点矿；风暴负责让宇宙更热闹。</li>
<li>本级开放活体金属生产与相关法令，记得提前准备后续材料。</li>
</ul>

<h3>天灾3级</h3>
完成<i><b>万门之门</b></i>并达到下一级要求后，解锁<i><b>银时之匙</b></i>。
<ul>
<li>银时之匙建成后，解锁<b>生成</b>与<b>收割</b>：一个重组星系，一个把星系拆成资源。</li>
<li>本级开放纳米机器人生产与相关法令，继续为巨构升级做准备。</li>
</ul>

<h3>天灾4级</h3>
完成<i><b>银时之匙</b></i>后，继续推进至<i><b>永恒王座</b></i>。
<ul>
<li>永恒王座建成后，解锁<b>播种</b>与<b>打击</b>。</li>
<li>打击会召来亚弗戈蒙的弱化化身，强度随游戏难度与天灾倍率缩放，<b>不分敌我</b>。别把自己的舰队也留在现场看热闹；击败这种主动召来的化身不算完成终局。</li>
</ul>

<h3>天灾5级</h3>
完成<i><b>永恒王座</b></i>并达到五级后，可以升级最终巨构<i><b>犹格索托斯</b></i>。五级奖励<b>超越因果</b>会缩短播种、收割、打击和抹除的额外冷却。
<br>
犹格索托斯完工后，<b>自动开启亚弗戈蒙终局</b>，不会直接飞升。把现实改得太离谱，宇宙的纠错机制找上门了。

<h3>DAIT菜单怎么用？</h3>
从万门之门开始，底部会出现固定悬浮球，点击展开菜单；也可以通过<b>应用无限菜单</b>法令直接打开并展开。
<ul>
<li>先选中目标，再选操作和适用范围，最后点击<b>确认</b>。仅进入星系视图不算选中；被抹除的空星系可以点击<b>虚空</b>对象，再使用生成重建。</li>
<li>右上角“×”只收起菜单、保留悬浮球；右下角<b>退出菜单</b>才会彻底关闭，可通过法令重新打开。</li>
<li>飞升前所有操作都消耗超然逻辑。丰饶即时生效，其余操作有生效时间，施放后的进度在局势中查看。</li>
</ul>

<h3>终局：调查、诱导、约束，然后揍祂</h3>
终局会同时显示研究进度与本轮降临局势，目标和剩余时间以局势为准。
<ul>
<li><b>先让祂留下残迹。</b>首轮前兆为300天，之后每轮缩短60天，最低180天。未约束化身降临后驻留180天，超时会抹除当地星系，留下可调查的残迹。派遣配有科学官的科研船完成60天现场调查，每处残迹只计一次。</li>
<li><b>调查1处：</b>掌握降临周期。<b>调查2处：</b>解锁诱导降临。<b>调查3处：</b>解锁诱导并约束降临。主研究局势不会靠挂机自行完成。</li>
<li><b>把祂引到准备好的战场。</b>选中外部星系后，在DAIT菜单底部点击诱导或约束。诱导消耗10,000超然逻辑；约束另外需要2,000暗物质，并同时完成诱导。两种项目都需要科研船进行60天现场研究，必须在显现前完成，改变目标不会重置倒计时。</li>
<li><b>别让祂回家。</b>前五轮会寻找外部星系，之后会把目标对准无名之雾；若提前找不到有效的外部目标，也可能更早回头。必须及时诱导，<b>祂抵达无名之雾就会立即判负</b>，无名之雾与穷极之门一并被抹除。</li>
<li><b>最后才是舰队的工作。</b>约束成功后，化身会保留720天战斗窗口，强度同样随游戏难度与天灾倍率缩放。必须在驻留期限内击败<b>本次终局的受约束化身</b>才能获胜；做完研究、击败未约束化身或自己召来的打击化身都不算。拖到超时，当地星系仍会被抹除。</li>
</ul>

<h3>胜利之后</h3>
击败亚弗戈蒙后，可以选择<b>迈入门后</b>立即进入飞升结局，也可以<b>留步凝望</b>，保留当前帝国继续玩。
<br>
选择暂留会获得不限期、零费用的<b>晋升</b>特殊项目。什么时候准备好了，研究30天就能再次选择，也可以继续暂留。
<br>
<b>确认飞升后才会清理原有殖民地并转变帝国形态。</b>此后解锁思潮与抹除，打击升级为完全体，所有DAIT免费、免冷却，有生效时间的操作仍需等待。全境打击会记录施放时中心星系的目击帝国，生效时向其领土传播；游牧帝国还会覆盖其舰队当时所在的有效星系，同一星系只打一次。化身依然不分敌我，飞升了也别忘了这个。

<h2>兼容性</h2>

该mod存在移除天体、舰船等行为，可能会导致其他mod的特殊天体、星系、舰船被错误的移除导致事件链卡住。
<b>严重警告：</b>请不要使用mod的地图类型！这可能导致<i><b>无名之雾</b></i>无法生成并阻断天灾进度！
<br>

最后，享受游戏吧！
