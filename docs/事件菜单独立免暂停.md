# 事件菜单独立免暂停

记录日期：2026-10-16。适用环境：Stellaris 4.5。本项目使用 DAIT 菜单验证，作者已确认免暂停生效。

## 实现原理

事件窗口的显示与自动暂停由消息类型分别控制。普通事件使用原版 `EVENT_MESSAGE_TYPE`，其定义包含 `default_popup = yes` 和 `default_autopause = yes`，因此显示窗口时默认暂停游戏。

事件可以通过 `event_message_type` 改用独立的消息类型。为 DAIT 定义一个“显示窗口，但默认不暂停”的类型，就能让菜单首次打开和超时续开都使用自己的设置，其他事件仍使用原来的消息类型。

这里设置的是自动暂停的默认值，不是弹窗后强制恢复时间。如果玩家原本已经暂停游戏，打开 DAIT 不应替玩家解除暂停。

## 1. 定义独立的消息类型

新增文件 `common/message_types/AIO_message_types.txt`：

```text
message_type = {
    key = "AIO_DAIT_MENU"
    name = "AIO_DAIT_toolbar"
    icon = "GFX_message_other_alert"
    icon_frame = 1
    category = other
    hidden_in_message_settings = yes
    default_notification = no
    default_toast = no
    default_popup = yes
    default_autopause = no
    can_disable = no
}
```

| 字段 | 本项目的作用 |
|---|---|
| `key` | 消息类型标识，事件通过这个值引用它；使用模组独有名称避免冲突。 |
| `name` | 消息类型名称的本地化键；这里复用已有的 `AIO_DAIT_toolbar`。 |
| `icon`、`icon_frame` | 消息图标及帧，复用原版资产。 |
| `category` | 消息设置中的分类。 |
| `hidden_in_message_settings` | 隐藏该类型的消息设置条目，避免内部菜单宿主占用设置列表；它本身不负责免暂停。 |
| `default_notification` | 默认不生成顶部通知。 |
| `default_toast` | 默认不生成角落提示。 |
| `default_popup` | 默认显示事件窗口，保留自定义菜单。 |
| `default_autopause` | **核心设置：默认不因这类消息自动暂停。** |
| `can_disable` | 沿用原版事件消息的设置，禁止禁用该消息类型。 |

文件中允许包含多个 `message_type` 定义，每个定义的 `key` 必须独立。新增自己的文件即可，无需复制或覆盖原版 `00_message_types.txt`。

## 2. 将菜单事件关联到消息类型

在 `events/AIO_DAIT_events.txt` 的 `AIO_DAIT_events.203` 中添加：

```text
event_message_type = AIO_DAIT_MENU
```

它是事件的顶层属性，与 `title`、`desc`、`diplomatic`、`custom_gui` 同级。本项目对应片段如下，其余触发条件和效果省略：

```text
country_event = {
    id = AIO_DAIT_events.203
    title = AIO_DAIT_events.202.title
    desc = AIO_DAIT_menu_desc
    event_message_type = AIO_DAIT_MENU
    diplomatic = yes
    custom_gui = AIO_DAIT
    is_triggered_only = yes

    # 此处保留原事件的 trigger、immediate、option 等定义。
}
```

`event_message_type` 引用的是消息类型的 `key`，不是文件名，也不是名称本地化键。它不放在 `immediate` 或选项效果中。

## 3. 与菜单自动续开的关系

DAIT 的 GUI 挂在 `.203` 事件上。事件正常结束后，`after` 延迟一个游戏日调用隐藏事件 `.205`，再由 `AIO_DAIT_ensure_menu` 检查是否需要重新打开 `.203`。操作、范围和展开状态保存在国家变量或标记中，续开时保留。

独立消息类型配置在 `.203` 上，因此通过法令、读档、巨构完成或自动续开打开它时，都会使用同一套免暂停默认值。无需给每个入口分别添加处理，也无需定期检查暂停状态。

通过法令手动打开时，入口设置一次性的 `AIO_DAIT_expand_on_open` 标记，`.203` 完成初始化后展开面板并清除此标记，确保首次使用也能直接看到菜单。其他自动入口保持原有的展开／收起状态处理。

右上角 × 只收起面板，保留悬浮球；悬浮球可展开或收起面板。右下角“退出菜单”按钮才会设置 `AIO_DAIT_dismissed`，关闭宿主并阻止自动续开。这套生命周期与免暂停配置分别负责窗口存续和消息行为。

## 验证方法

修改消息类型后重启游戏，再进行以下检查：

1. 时间正在推进时，用法令打开 DAIT，确认时间继续推进。
2. 保持菜单宿主运行，等待事件自动结束并续开，确认续开不触发暂停。
3. 手动暂停后打开菜单，确认游戏仍保持暂停。
4. 触发普通事件，确认它仍遵循玩家原有的暂停设置。
5. 点击右上角 ×，确认仅收起面板，悬浮球和选择保留；再通过悬浮球展开，点击右下角“退出菜单”，确认面板和悬浮球隐藏且不会自动续开。通过法令重新打开后，操作与范围保留。

`default_autopause` 是默认设置，不应理解为对所有既有用户消息设置的强制覆盖。若其他模组覆盖同名消息类型，或本机存在该类型的自定义设置，需要核对最终生效的定义和设置。

本项目的静态检查及离线测试可以检查脚本结构，但不模拟引擎暂停行为；免暂停是否生效以游戏内测试为准。

## 依据

- 本机原版 `common/message_types/00_message_types.txt`：文件开头说明各个 `default_*` 字段，`EVENT_MESSAGE_TYPE` 默认启用自动暂停；`ENCLAVE_DIPLOMACY` 展示了独立外交事件消息类型的用法。
- 本机原版 `events/leviathans_events_1.txt`：使用 `event_message_type = ENCLAVE_DIPLOMACY`。
- [官方开发日志 #374](https://steamcommunity.com/games/281990/announcements/detail/508448342467937917)：说明新增 `event_message_type`，允许事件覆盖默认消息类型并拥有独立的消息设置。
