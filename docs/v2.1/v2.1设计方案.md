# AIO v2.1 设计方案

> 2026-10-15。v4 的大球路线放弃，回到以**定向应用无限（DAIT）**为核心的 v2，并吸收 v4 的亚弗戈蒙终局。本文是交给实现者的依据，数值标"建议"的可在实测后调整。

## 1. 基线与分支

- **基线**：v2（`main`），合并进当前为 v4 的 `preview`，以 v2 的玩法为准，v4 只保留第 7 节列出的内容。
- 注意：`main`（`95b27ad`）不是 v2 的最后一个提交。v2 最后还有 `6bc4c3e`（"天陨广光矛aoe, 递归节点提供全国岗位效率加成"），它在 preview 的历史里、不在 main 上，需要一并带上。`14b3155` 起是 v3，不要。
- v4 的大球（无名之雾殖民地、mist 区划/岗位/特化）、规则科技（`AIO_rule_*`、`AIO_AIT_events`）、v4 远程投射都不移植。

## 2. 核心循环

```text
天灾等级 / 巨构 → 解锁 DAIT 操作
选中星系 → 常驻菜单施放（付超然逻辑）→ 前摇 → 按范围档位生效
五级：完成犹格索托斯 → 亚弗戈蒙追索 → 击败 → 飞升，解锁禁忌操作
```

v2 的"万物归谬"局势（在局势中重复播放用过的效果）整体移除，见第 6 节。

## 3. 等级与操作

沿用 v2 的巨构门槛（`AIO_DAIT.fail.require_mega_*`），等级门槛去掉局势阶段 flag（见 6.2）。

| 解锁时机 | 操作 | 说明 |
|---|---|---|
| 万门之门（`AIO_mega_01`） | 丰饶、风暴 | 风暴保留，维持每级两个操作的对称 |
| 银时之匙（`AIO_mega_02`） | 生成、收割 | |
| 永恒王座（`AIO_mega_03`） | 播种、**打击（弱化亚弗戈蒙）** | 打击即召唤亚弗戈蒙，此时只能召出弱化体 |
| 五级：犹格索托斯（`AIO_mega_04`） | **不解锁新操作** | 完成即开启亚弗戈蒙终局（第 5 节） |
| 击败亚弗戈蒙 | **思潮反转、擦除**；打击升级为**完全体** | 飞升胜利同时获得 |

v2 中思潮、擦除原本由犹格索托斯解锁，现改为击败亚弗戈蒙后解锁。叙事：把东西从时间中抹去、改写一个文明的意志、驱使时间之神，都需要先约束亚弗戈蒙。

### 3.1 亚弗戈蒙两种形态

强度直接复用 v4 终局中的两种化身：

| | 弱化体（四级起） | 完全体（击败后） |
|---|---|---|
| 舰队强度 | v4 **受约束**的化身 | v4 **未受约束**的化身 |
| 驻留 | 较短，建议 180 天 | 360 天 |
| 抹除星系 | 不会 | 驻留结束抹除星系，留下残迹 |
| 前摇 | 较长 | 较短 |

保留 v2 中 AIO_empire(飞升后) 施放打击会在**所有目击帝国的全部星系**同时生成倒影，飞升前范围统一由第 4 节的范围档位决定。

## 4. 操作通用规则

### 4.1 范围与前摇

- 单星系效果本轮**沿用现有数值**，不加大；数值以后按实测调整。
- **范围档位**：菜单上一个循环切换按钮，0 / 1 / 2 跳（建议），作用于目标星系及其范围内星系。不为每档单独做按钮。`AIO_DAIT_erase_effect` 已有 `MAX_JUMPS` 参数，其他操作按同一写法扩展。
- **前摇**：施放时扣费，保存目标星系、档位、施放者，经延迟事件生效。档位越大，前摇越长、费用越高。建议基础前摇 90 天，每档 +90 天；完全体打击、擦除另加。
- 前摇期间：
  - 目标星系显示特效（emmm我没有资产，所以我也不知道怎么加好），向范围内有殖民地或舰队的国家发通知（复用 v2 的 230～237 受影响通知文本，使用 create_message 接口而非弹窗事件）；
  - 同一星系同时只允许一个前摇中的操作。
- 生效时**重新校验**：目标是否仍存在、是否仍合法（例如不再是危机/API 排除星系），不合法则取消，并返还一半费用（建议）。v2 曾出现 event target 丢失（`97ced2d`），前摇会放大这类风险，生效事件只依赖保存在事件上的 target，不依赖全局 event target。
- 每个操作单独冷却（建议 360 天）。AIO_empire 沿用 v2：免费，但仍有前摇与冷却。

### 4.2 不做"控制台"

目标单位保持**星系**。需要更细粒度的效果时：

1. **效果由目标决定，不由参数决定**：改天体按当前类型映射，思潮反转按固定对照表，丰饶按天体类型选矿藏。
2. 确实需要玩家选择时，**生效时弹一次性事件**给选项，不常驻在菜单里。

思潮反转沿用现有 `AIO_DAIT_ethic_effect`：排外↔亲外、军国↔和平、威权↔平等、唯心↔唯物，狂热度保持，随后 `change_government = random` 处理与新思潮冲突的政体和国民理念。

## 5. 亚弗戈蒙终局

从 v4 移植终局局势（第 7 节），触发点为**犹格索托斯完成**，胜利条件为**击败受约束的化身**，失败条件沿用 v4（化身抵达无名之雾则失败，清除无名之雾与穷极之门）。

### 5.1 缩短时长

玩家反馈：固定计时导致终局"起码十年"，从 2201 年飞升、三倍速、控制台无限资源也打到 2240 年。v4 现值的问题主要是首轮前兆 `@AIO_final_base_wait = 2000` 天。

| 变量 / 项目 | v4 现值 | 建议 |
|---|---:|---:|
| `@AIO_final_base_wait` 首轮前兆 | 2000 | 540 |
| `@AIO_final_sub` 每轮缩短 | 200 | 120 |
| `@AIO_final_min_wait` 前兆下限 | 200 | 180 |
| `@AIO_final_research_cost` 调查/现场项目 | 360 | 180 |
| `@AIO_final_exist_time` 驻留 | 360 | 360 |
| 残迹门槛（周期 / 诱导 / 约束） | 1 / 2 / 6 | 1 / 2 / 3 |

目标：正常速度下，从犹格索托斯完成到可以击败化身约 4～5 年。改门槛时同步局势、按钮、事件校验、里程碑通知与中英文案（参照 v4 实施记录 2026-10-14 的那次调整）。同时校验"约束解锁时剩余前兆 ≥ 现场项目时长"，这是 v4 上次调门槛的原因。

### 5.2 胜利

- 击败化身 → 飞升胜利事件（沿用 602 文本与 `win = yes`），转为 AIO_empire，解锁思潮反转、擦除，打击升级为完全体。
- v4 的胜利后远程投射（`AIO_projection_*`、单星系锁定 + 风暴 + 720 天召唤）**不移植**，由菜单中的完全体打击取代。

## 6. 移除与改造

### 6.1 万物归谬局势与 echo

整体删除：

- `common/situations/AIO_crisis_situations.txt`
- `common/scripted_effects/AIO_DAIT_echo_effects.txt`
- `common/scripted_triggers/AIO_DAIT_echo_triggers.txt`
- 引用它们的事件、on_action、POI、本地化

### 6.2 等级门槛

v2 的 3～5 级 `allow` 要求 `AIO_crisis_situation_stage_*_complete`，随局势删除。改为只看巨构完成 flag + 天灾货币。v2 货币门槛为 2000 / 6000 / 18000 / 45000，删除局势后需要重新核对超然逻辑的获取速度，必要时下调。

### 6.3 锁定目标入口

删除 `AIO_test_scripted_action_megastructure.txt` 和 `AIO_DAIT_scripted_actions.txt` 的"锁定现实坐标"流程，改造 202 菜单事件（`custom_gui = AIO_DAIT`），由第 8 节的常驻菜单取代。

## 8. 常驻菜单

### 8.1 目标

- 一条小横栏，可以一直开着，不挡视野。
- 自动读取当前选中的星系；在星球界面时取该星球所在的星系。
- 内容：当前目标星系名、一排操作图标、范围档位按钮。费用、前摇、冷却、不可用原因放在悬停提示里。

### 8.2 作用域约束（v2 踩过的坑）

`AIO_DAIT_menu.txt` 顶部注释：THIS 是选中对象且会变化，FROM 是玩家国家。

- `potential` 只写在 FROM 上。
- `allow` 中先判断 THIS 的类型（星系，或可以取到星系的星球），再判断操作条件；类型不对时置灰，并提示"请选中一个星系"。
- 点击时立即把目标星系存成事件 target，交给前摇事件，按钮 effect 内不做长链操作。

### 8.3 M0 需先验证

- 横栏挂在哪里：原版界面中能稳定提供"当前选中对象"作用域的位置，以及能否做成常驻开关窗口。
- 是否必须覆盖原版 `.gui`。必须覆盖时，记录覆盖的文件名，评估与其他 UI mod 的冲突。
- 星系视图、星球视图、银河地图三种状态下 THIS 的实际取值。
