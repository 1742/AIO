# AIO v2.1 设计方案

> 2026-10-15，根据玩家反馈及作者确认修订。放弃 v4 大球路线，回到以**定向应用无限（DAIT）**为核心的 v2，保留亚弗戈蒙终局。玩法取舍按本文执行；标“建议”的数值用于首轮实现和实测，不代表已经验证。代码已按此方向重建，当前为待游戏内验收版本；实现情况与验收项见 [v2.1实施记录](v2.1实施记录.md)。丰饶、生成按作者最新调整移除国家 buff，只保留星系直接效果。

## 1. 反馈、目标与基线

### 1.1 要解决的问题

玩家接近原版环境、数值 mod 较少，反馈集中在：

- 中期巨构资源需求麻烦，早期缺少能改善经济的能力；旧版丰饶、粉碎星球有用，应恢复主动收益。
- 大球依赖填岗，非虚拟不舒服，虚拟则很强。大球挤占了应用无限的玩法，无名之雾放殖民地也削弱了超然空间的代入感；作者认同这一方向。
- 希望改天体、改文明、毁灭星系，喜欢亚弗戈蒙不分敌我的力量。风暴偏代入用途，仍保留。
- 终局固定等待太久。玩家报告从2201年开始飞升，用控制台无限资源、三倍速仍玩到2240年才完成；这是整条飞升流程的体验，不能全归因于终局。
- 旧套娃脑随迁都失效，需要修复。特殊国策改写与更多稀有资源是额外愿望，边界见第10节。

目标是恢复主动改写宇宙的玩法，让早中期已有实用收益；经济由 v2 巨构、套娃脑和 DAIT 支撑，终局保留调查与战斗，缩短机械等待。

### 1.2 基线与回退方式

- **完整基线为 `6bc4c3e`**（“天陨广光矛aoe, 递归节点提供全国岗位效率加成”）。`main` 的 `95b27ad` 少了这次修改；`14b3155` 起为 v3。
- 设计阶段的 `preview` 参考点为 `e077fc5`。现已以 v2 文件树重建运行内容，并按第7节移植；把 `main` 合并进 `preview` 不会自动撤销 v3/v4。
- 保留 v4 参考点 `v4.0`（当前 `98ac0d0`）及本设计稿，不通过重写历史实现内容回退。不考虑旧存档兼容。
- 不保留 v3 光环、反噬，以及 v4 无名之雾殖民地、mist 区划/岗位/特化、规则科技（`AIO_rule_*`、`AIO_AIT_events`）和远程投射。
- 保留**非格式塔帝国可选**及配套适配。特殊起源恢复**直接飞升**并获得完整 DAIT 权限，不再经历终局；不伪造一次击败化身的事件。

## 2. 核心循环与经济

```text
研究 / 套娃脑 / 巨构 → 积累天灾进度与超然逻辑
天灾等级 / 巨构 → 解锁 DAIT 操作
选中星系 → 菜单施放 → 前摇 → 按范围生效 → 部分操作进入独立冷却
五级：完成犹格索托斯 → 自动开启亚弗戈蒙终局 → 三处残迹调查 → 约束并击败化身 → 选择飞升或保留当前帝国继续游玩
```

移除 v2 的“万物归谬”局势及 echo，不再重复跑局势才能升级。保留无名之雾及门的空间结构，**雾内不建殖民地，也不在门口另造 v4 大球**。

### 2.1 套娃脑

- 改为**一个区划即可解锁无限递归节点岗位**，不靠重复铺区划扩充岗位。建议同一殖民地最多一个；是否需要全国唯一限制不作为已确认要求，首轮不额外增加。
- 解除首都绑定，普通殖民地或适用的舰载殖民地按条件建造。迁都不拆除既有区划、不禁用岗位，也不丢失相关建筑、人口及收益。
- 统一区划身份，清理 v2 的 frame → 特化 → swap 占位区划转换链；保留仍有作用的建筑入口，按4.5区划/特化结构实现。
- **禁止虚拟人口担任递归节点**。虚拟帝国恢复 v2 的实体递归载体（`trait_AIO_recursive_chassis`），包括创建、休眠岗位及相应决议，不能由虚拟自动填岗绕过人口成本。
- 沿用 v2 节点产出、维护、损耗及 `6bc4c3e` 的全国岗位效率加成作为初始基准。无限岗位不等于无限住房、免费人口或无损耗。
- 非格式塔必须能实际使用：核对阶层、岗位资格、物种权利、损耗及载体，不直接照搬 `can_fill_drone_job` 就视为完成适配。
- 所有按 `capital_scope` 统计的节点收益改为统计实际套娃脑殖民地，包括 `crisobj_AIO_neural_chips`、script values、事件及提示。载体生成也定位实际承载殖民地，不再默认首都。

### 2.2 经济与成长节奏

先恢复 v2 经济，再测“第一扇门→首次丰饶→后续巨构”的闭环。v2 内部门月产1000超然逻辑，DAIT 基础费100000；仅靠门产出首次操作也需100个月，因此不能把“恢复 v2”直接当成早期收益已解决。

建议丰饶、生成、风暴基础费先采用 v2 的一半，即50000；其余付费操作100000。保留巨构各阶段产出及套娃脑供给，记录首次可施放时间后再调整，不一次修改所有经济参数。

中期巨构按 v2 起步，但必须复核暗物质、活体金属、纳米机器人的来源和积累时间。资源来源须早于需要支付的阶段；不能靠控制台、虚拟人口或外部数值 mod 才能通关。巨构工期也纳入完整飞升耗时，不能只缩短终局。

## 3. 等级与操作

沿用 v2 巨构门槛（`AIO_DAIT.fail.require_mega_*`），去掉局势阶段 flag。

| 解锁时机 | 操作 | 说明 |
|---|---|---|
| 万门之门（`AIO_mega_01`） | 丰饶、风暴 | 提前提供可用收益，风暴保留代入用途 |
| 银时之匙（`AIO_mega_02`） | 生成、收割 | 恢复生成特殊星系与取得资源的玩法，生成行为见4.3 |
| 永恒王座（`AIO_mega_03`） | 播种、打击 | 打击召唤弱化体 |
| 五级：犹格索托斯（`AIO_mega_04`） | 开启终局，不新增操作 | 已有操作继续可用 |
| 击败终局受约束化身 | 思潮反转、擦除 | 暂留当前帝国也可使用，仍需费用与适用冷却 |
| 确认飞升 / 特殊起源直接飞升 | 打击升级完全体、全境范围；全部操作免费、免冷却 | 仍保留生效时间 |

“抹除”在操作命名上统一沿用“擦除”。思潮、擦除在终局胜利时解锁，无需先转换国家类型；叙事是取得约束亚弗戈蒙、改写文明意志与抹除时间的能力。

### 3.1 打击的两种形态

| 项目 | 弱化体（四级起） | 完全体（飞升后） |
|---|---|---|
| 舰队强度 | 复用 v4 受约束化身设计 | 复用 v4 未受约束化身设计 |
| 驻留 | 建议180天 | 360天 |
| 驻留结束 | 消失，不抹除星系 | 抹除星系，留下残迹 |
| 阵营行为 | 不分敌我 | 不分敌我 |
| 范围 | 0／1／2跳 | 0／1／2跳，另有全境档 |

打击化身与终局化身共享舰船资产，**不共享胜利资格**。所有化身统一使用原版终局天灾的难度与天灾倍率缩放。击败自己召出的弱化体不能飞升；主动打击残迹不提供终局研究次数。状态、清理和舰队死亡回调须区分来源。

### 3.2 飞升后全境打击

优先把“全境”放进同一个范围循环按钮，仅完整权限时出现。此档仅打击可用，其他操作提示切回跳数档，不另做常驻参数面板。

建议明确以下规则，替代 v2 隐含传播行为：

- 施放时以中心星系为目击现场，记录其中舰队所属帝国，包含游牧帝国，排除化身所属国。提示解释全境含义，不按传感器视野判断。
- 生效时向中心星系及这些帝国当时拥有的全部合法星系召唤；游牧目击帝国还纳入其全部舰队生效时所在的合法星系，无须拥有该星系。按星系去重，无目击帝国则只作用于中心。
- 普通帝国不通过其外出舰队扩大目标集合；游牧帝国以生效时舰队位置补足无领土的目标范围，不持续追踪移动舰队，也不因新生成分身递归传播。前摇期间进入现场的国家不追加为目击者。
- 不过滤施放者、盟友或中立国，符合条件同样可能被波及；分身继续不分敌我。
- 若 M0 无法稳定支持动态档位，先采用独立的一次性全境选项；保留玩法，不宣称 GUI 能力已验证。

## 4. 操作通用规则

### 4.1 范围、费用、前摇与冷却

单星系效果以 **v2 基线**为准，暂不扩大单次效果数值。通用范围0／1／2跳，0跳仅中心；按超空间航道计算，不经过 bypass。每个星系只处理一次，思潮反转按国家去重，避免同一帝国连续反转回原状。

**所有 DAIT 在飞升前均须支付超然逻辑，只有已飞升的 AIO_empire 统一豁免费用。**费用与操作解锁条件分开判断，不因某项操作当前只在飞升后解锁就把其基础费定义为零。表中为未应用飞升豁免的初始建议参数，不改变第3节的解锁顺序：

| 操作 | 0跳基础费 | 0跳前摇 | 生效后的额外冷却 |
|---|---:|---:|---:|
| 丰饶 | 50000 | 即时，所有范围均无前摇 | 无 |
| 生成、风暴 | 50000 | 90天 | 无 |
| 播种、收割 | 100000 | 90天 | 360天 |
| 打击：弱化体 | 100000 | 180天 | 360天 |
| 打击：完全体 | 100000 | 90天 | 360天 |
| 思潮反转 | 100000 | 90天 | 无，作为本稿建议 |
| 擦除 | 100000 | 180天 | 360天 |

- 1／2跳费用分别为基础费的2／3倍，前摇加90／180天。先按档收费，不逐星系算价。
- **所有操作各自计时**：每个国家、每种操作最多一个待生效施放；同一种操作须等本次结算及自身冷却结束，其他操作不受影响。两种形态的打击共用同一操作计时。
- 播种、收割、打击、擦除需要前摇加额外冷却；丰饶即时生效，生成、风暴只有前摇。额外冷却从成功生效开始计算。切换目标或档位不重置计时。
- AIO_empire 全部操作免费，仍遵守相应前摇和冷却。全境打击建议前摇360天、冷却360天。
- 擦除的 v2 飞升后固定5跳改为可选，**建议额外保留5跳档**，前摇基础值加450天；此档仅擦除可用。这是对尚未明确的范围细节的建议，实测可调整。
- 范围算法只展开一层，不能外层逐星系调用后再套底层 `MAX_JUMPS` 扫描，扩大实际作用范围。

### 4.2 施放与结算

施放时验证权限、费用、计时和中心目标，扣费并保存本次施放者、中心、操作、档位、实际费用及形态。除即时丰饶外，每次施放创建施放者所属的独立局势，保存中心目标并管理前摇、有效性校验和结算，不再使用延迟事件计时，也不能依赖会被后续点击覆盖的全局目标。读档后仍按原信息结算。

- 跳数档施放时确定候选星系集合，后续复核合法性，不因航道变化增加未预警目标。全境档按3.2保存目击国家，最终领土按生效时计算。
- 同一中心星系只允许一个前摇中的操作；范围重叠不等于锁住整个区域。每次结算独立复核，被先前操作改变的目标按新状态处理。
- 使用已有游戏资产作目标标记，M0 核实具体资产。不向其他国家发送前摇通知；仅在实际触发效果时通知受影响国家。使用 `create_message` 并按国家去重。
- v2 的230～237是生效通知，不能原样冒充预警。施放者通过局势查看目标、范围、预计生效日期和剩余时间；其他国家只接收“已经生效”的通知。
- 生效时逐目标校验危机保护与 API 排除条件；中心失效则取消，其他目标失效只跳过。所有目标均无有效效果时按失败处理。
- 失败建议返还**实际已支付费用的一半**，不产生额外冷却；免费操作不产生退款。部分成功不逐目标退款。
- 成功、取消或施放者灭亡均须清理对应占用及临时标记。终局胜负路径也须检查待生效操作的权限，但只能释放相应施放的锁，不能错误清除其他操作。
- 失去施放资格时取消。飞升不改变已经在前摇中的弱化体，本次形态以施放时记录为准。

### 4.3 不做“控制台”

目标单位保持星系，沿用 v2 的“生成”操作，不新增独立的“更改天体类型”操作或按类型映射机制。生成包含清空星系内容后重新生成特殊星系的玩法；这里清空的是星系内对象，不是删除银河地图上的星系节点。

基线核对：`6bc4c3e` 的 `AIO_DAIT_spawn_effect` 在虚空星系（`sc_AIO_void`）或已收割星系上清理原有天体、巨构和环境对象，再从七种特殊布局中随机生成，并移除收割标记；普通星系另有随机调整恒星及符合条件的未殖民自然天体类型、大小的旧分支。这些属于同一个“生成”操作，不是类型映射表。移植按实际分支核对，不擅自添加映射设计，也不将所有目标无条件清空误记为 v2 现状。

范围生成逐个处理候选星系，清理与重建不得使后续目标集合或施放上下文失效。清理细节参照6.4。确实需要玩家选择时用一次性事件，不把参数堆在常驻菜单上。

思潮反转沿用 v2 四轴对照：排外↔亲外、军国↔和平、威权↔平等、唯心↔唯物，保持狂热度。按生效前的思潮快照转换；格式塔等不适用目标须给出原因。`change_government = random` 仅是既有政府适配实现，不能据此承诺可以获得或移除种族洁癖等特殊国策。

## 5. 亚弗戈蒙终局

犹格索托斯完成后启动。保留**三处不同残迹调查→现场约束→击败受约束化身**。化身抵达无名之雾则失败，清除无名之雾与穷极之门，沿用 v4 失败表现。

### 5.1 节奏建议与时间线

原稿540天首轮、每轮减120天、360天驻留，前三轮就要2340天；再做180天调查会耗尽第四轮180天前兆。因此拆开调查、现场研究、普通显现及约束战斗时间，不共用一个驻留参数。

| 项目 | v4 基线 | v2.1 建议 |
|---|---:|---:|
| 首轮前兆 | 2000天 | 300天 |
| 每轮缩短 | 200天 | 60天 |
| 前兆下限 | 200天 | 180天 |
| 残迹调查 | 360天 | 60天 |
| 诱导／约束现场项目 | 360天 | 60天 |
| 未约束化身驻留 | 360天 | 180天 |
| 受约束化身战斗窗口 | 360天 | 720天 |
| 调查门槛：周期／诱导／约束 | 1／2／6 | 1／2／3 |
| 项目有效期 | 1000天 | 1000天，现场项目仍在显现时中止 |

不计赶路、月结误差与轮次间1天调度延迟的理想时间线：

| 时间 | 进度 |
|---|---|
| 第300天 | 第一轮显现 |
| 第480天 | 第一处残迹，第二轮开始 |
| 第540天 | 第一次调查完成，掌握周期 |
| 第900天 | 第二处残迹，第三轮开始 |
| 第960天 | 第二次调查完成，解锁诱导 |
| 第1260天 | 第三处残迹，第四轮开始 |
| 第1320天 | 第三次调查完成，解锁约束 |
| 第1380天 | 可完成现场约束，距显现约60天 |
| 第1440天 | 受约束化身显现，进入最终战斗 |
| 第1800天前 | 须击败化身；未击败则按既有规则继续追索 |

理想情况下约4年进入战斗、5年内获胜。这是**游戏内时间**，不是现实游玩耗时保证。调查与下一轮前兆并行，舰队和另一艘科研船可提前部署；赶路和调度会延长流程。

第四轮前兆须容纳“第三次调查＋约束项目＋赶路余量”。理论余量60天，实测不足时优先缩短调查/普通驻留或适当增加前兆，不压缩最终战斗窗口。验收包含正常科研船赶路，不用瞬移得出可行结论。

### 5.2 状态与失败压力

- 前兆建议按 `max(300 - 60 × round, 180)` 计算，round 从0开始。
- 沿用 v4 前五轮优先外部星系、之后默认指向无名之雾的压力机制；仍可通过诱导/约束重定向。保留失败可能。
- 两种驻留时长须同步反映在局势总进度、阶段权重、提示和清理时机上。约束完成后切换720天战斗窗口，不能仍按180天结算。
- 门槛同步修改局势、按钮、事件、触发器、里程碑和中英文案。取消项目、转移目标不重置前兆。
- 终局与主动打击不得争用化身标记。已有化身、保护星系、被擦除目标由共同合法性检查处理；主动打击分身与残迹不推进终局，也不能触发终局胜利。

### 5.3 胜利

只有本次终局所属的受约束化身被有效击败才能胜利。胜利先结束终局并打开601选择：立即进入602飞升结局，或保留当前帝国继续游玩。暂留会启用不限期、研究30天的“晋升”特殊项目，完成后再次打开601，仍可选择暂留。仅确认602结局时执行 `win = yes`、转为 AIO_empire、清理殖民地、解除附庸关系并解锁完整 DAIT；结算只执行一次。
