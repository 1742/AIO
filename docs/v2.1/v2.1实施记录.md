# v2.1 实施记录

2026-10-15。当前代码以 `6bc4c3e` 的 v2 运行内容重建，移入亚弗戈蒙终局并适配 4.5。此记录区分代码实现与游戏内验证；未完成实机验收，不能作为已发布版本的测试结论。

## 已实现

- 保留非格式塔入口；特殊起源直接飞升。起源先登记门、创建雾、转换国家类型，再清空原首都星系，避免清掉最后一个殖民地后才转换国家类型。
- 移除 v3/v4 大球、规则科技、远程投射，以及 v2 的旧局势和 echo。无名之雾与门使用 `AIO_mist_*`、`AIO_gate_*` 命名。
- 套娃脑统一为一个区划，每殖民地最多一个，提供无上限递归节点岗位；移除首都绑定，按全国实际岗位统计。禁止虚拟人口填岗，保留实体递归载体、休眠岗位与决议。
- 普通帝国补充活体金属生产特化，使用冶金师转化部分合金产能，补上专属巨构的材料来源。经济平衡仍需实测。
- 八种 DAIT 共用施放流程：验证、扣费、记录目标与范围、前摇、复核、执行、冷却、清理。每种操作独立计时；同一中心不允许同时前摇。延迟事件使用局部事件目标，不共用全局施放目标。
- 飞升前所有 DAIT 均有基础费，飞升后免费。无有效目标时退还实际支付的一半，不进入冷却。丰饶、生成按作者最新调整移除国家 buff，仅保留直接效果。
- 生成保留 v2 的特殊星系重建与普通天体随机变化分支，不引入天体类型映射表。安全移除参考原版 `destroy_star_system`：通知销毁、清除祝圣、轨道设施、建筑与地块、处理肃正枢纽、移除环境改造候选，并保留异次元入侵特效。
- 思潮反转先记录原思潮，再逐轴反转，保持狂热等级，范围内同一国家只处理一次。
- 打击召唤的化身与终局化身分开计数、计时和判胜。飞升后可选全境档：记录施放时中心星系舰队所属帝国，生效时扩展其疆域；不递归传播，不分敌我。
- 顶部工具栏提供开关、操作与范围入口；另保留巨构原生操作按钮和切换范围法令。两种入口接入同一施放流程。工具栏的运行时作用域仍是首要验收项。
- 中英提示、README 与工坊介绍同步到 v2.1；范围提示显示跳数或全境，不显示内部索引。

## 常驻菜单实测原型

已保留作者调整后的递归载体事件编号 `AIO_crisis_events.902`。
