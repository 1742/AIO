# 天灾奖励图标处理

工具：`tools/compose_reward_icon.py`，需要 Python 和 Pillow（`python -m pip install Pillow`）。以下命令在模组根目录执行。

用于把已有白色单色符号合入原版式边框，不负责生成图案。输出为144×72 RGBA DDS：左侧72×72亮帧，右侧72×72暗帧，适配 `noOfFrames = 2`。

## 使用

准备一张正常的旧奖励DDS作为边框模板，以及新图案PNG。默认输入PNG是左右两帧、宽高比2:1；工具只从左侧亮帧提取图案，右帧由同一图案生成，避免形状和位置漂移。

```powershell
python tools/compose_reward_icon.py --template gfx/interface/icons/crisis/AIO_menp_dimensionality.dds --source "C:/path/to/new_icon.png" --output gfx/interface/icons/crisis/AIO_menp_living_metal.dds --overwrite
```

当前 Codex 环境也可使用自带 Pillow 的 Python：

```powershell
& "$env:USERPROFILE/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe" tools/compose_reward_icon.py --help
```

- `--source-frames 1`：输入是单张图案。
- `--size 46`：符号最大宽高，默认46像素，保持比例并居中。
- `--dim 128`：暗帧符号灰度；边框仍来自模板自身的暗帧。
- `--output preview.png`：先输出PNG检查。DDS与PNG使用同一合成流程。
- `--overwrite`：显式允许覆盖目标文件；工具始终禁止覆盖模板或输入原图。

## 提取规则与限制

自动提取适用于黑底/透明底、浅色符号，且符号与新图自带边框分离的图片。它通过亮度阈值寻找连通区域，丢弃延伸到外侧边缘的区域及小噪点。可调整 `--threshold`（默认90）、`--margin`（默认0.113）、`--min-area`（默认0.00025）。

若符号碰到边框或提取不完整，可指定 `--symbol-box LEFT TOP RIGHT BOTTOM`，坐标以输入图的第一帧为准。这会直接裁取矩形中的亮度作为符号遮罩，因此矩形内不能包含不需要的新边框。

模板必须为144×72。清空区域使用本模组六边形的内部多边形，不适用于任意形状的边框。合成时符号限制在内部区域，内部之外的像素逐一核对，必须与模板完全相同，包括透明度。若换用不同版式，需要修改工具中的内部多边形。

建议先输出PNG，检查符号无残留、未被裁切、缩到72像素后仍可辨认，再覆盖DDS。脚本的像素检查不能替代视觉检查或游戏内检查。
